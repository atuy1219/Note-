# Note コードレビュー（2026-10-01）

対象: main、AGP 9.4.1更新後。ビルド設定、保存、Drive同期、Ink入力、UIを確認。

## 今回修正した問題

- 読み込めないストロークを `mapNotNullTo` で捨てて開くため、再保存で原本から線が消える。
- ZIP保存時に欠けた画像・Inkエントリーを飛ばすため、不完全なノートが正常保存扱いになる。
- アーカイブ・索引のrename失敗時に元ファイルを直接上書きするため、コピー途中の失敗で元データが壊れる。
- 自動保存の例外が未処理でアプリ終了につながる。キャンセルは通常の失敗と区別する必要がある。

## 残る構造上の問題

1. 保存スナップショットと編集世代管理は追加済み。ただし保存とライブラリ操作・Drive同期の全体排他は未完了。古いLibraryIndexを渡す競合が残る。
2. Driveから取得したノートを開いているタブへ再ロードしないため、次の保存で旧内容を上書きする可能性がある。同期と編集・保存を排他化したうえで、更新対象だけを再ロードする必要がある。
3. リビジョンの大小だけで上書き方向を決めるため、別端末で独立編集し保存回数が異なると競合コピーを作らない。前回同期ハッシュを用いた双方変更検出が必要。
4. 完全削除をDriveへ伝えないため、次回同期でノートが復活する。削除のtombstone設計が必要。
5. 共有ボタンは保存しか行わず、保存完了前に成功通知する。実際のexport/share機能は未実装。

保存中の新規編集がdirty=falseになる問題はスナップショットと世代比較で修正。保存開始後は次のペン入力でジョブをキャンセルしない。残る同期・索引の構造上の問題は、残存課題として記録する。実機でのペン入力・Drive同期は未検証。

## 検証

AGP更新PR #35: debug/releaseビルド、testDebugUnitTest成功。追加修正では、欠けた筆跡の読み込み拒否、保存スナップショットの独立性、保存中の編集のdirty維持をユニットテストで検証する。
